# Tripick 용어집

여행 일정의 생성, 저장, 공개에 쓰는 제품 용어다. 구현 방식과 API 필드명은 이 문서에서 정의하지 않는다.

## Language

**여행지**:
한 저장 일정의 방문 지역. 도시뿐 아니라 제주·발리처럼 섬이나 넓은 지역도 포함하며 한 일정에는 하나를 선택한다.
_Avoid_: 도시

**여행 조건**:
여행자가 일정 제안을 받기 위해 선택한 목적지, 날짜·기간, 동행, 취향 등 제약과 선호의 묶음.

**동행 인원 구간**:
여행 조건에서 선택하는 인원 범주. `4명 이상`은 정확한 인원수를 뜻하지 않는다.
_Avoid_: 정확한 동행 인원

**생성 결과**:
여행 조건에 따라 제안된 일정으로, 여행자가 아직 확정 저장하지 않은 결과.
_Avoid_: 저장 일정

**저장 일정**:
여행자가 명시적으로 저장해 자신의 일정 목록에 보관한 여행 계획. 같은 일정을 수정해 다시 저장해도 하나의 저장 일정이다.
_Avoid_: 생성 결과, 게시 일정

**저장 슬롯**:
한 계정이 동시에 보유할 수 있는 저장 일정의 자리. 생성 결과는 슬롯을 차지하지 않으며 저장 일정 전체를 삭제해야 자리가 돌아온다.
_Avoid_: 생성 횟수

**편집 작업본**:
저장 일정을 변경하는 동안의 미확정 내용. 변경을 확정하기 전의 저장 일정과 구분한다.

**게시 일정**:
다른 여행자가 볼 수 있도록 공개한 저장 일정의 사본. 원본 저장 일정과 별개의 공개 상태를 가진다.
_Avoid_: 저장 일정, 공유 링크

**공개 닉네임**:
여행자가 게시 일정의 작성자로 다른 사람에게 보여주기로 정한 이름. 로그인 신원과 구분한다.
_Avoid_: 이메일, 계정 ID

**하트**:
한 계정이 게시 일정 하나에 표시하는 선호 반응. 같은 계정이 같은 게시 일정에 동시에 둘 이상의 하트를 갖지 않는다.
